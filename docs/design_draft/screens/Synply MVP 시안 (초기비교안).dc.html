수정 모드 차이
같은 드로어 컴포넌트를 등록/수정 모드로 공용 사용합니다. 수정 모드에서는 ① 제목이 “지원 기록 수정”, 진입 시 기존 값을 불러오는 로딩 표시 ② 현재 전형 상태가 선택된 채 표시(상태 변경 흐름과 동일) ③ 연결된 이력서 파일에 연결 해제 버튼 노출 — 해제 시 “이력서 미연결” 상태로 전환. 저장 중에는 버튼이 비활성화되고, 필수값 누락 시 인라인 오류를 표시합니다.
